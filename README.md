# BAGÉ — бесплатный сайт-каталог

Это статический сайт на HTML, CSS и JavaScript. Он не требует платного хостинга, базы данных или программиста.

## Что уже работает
- Адаптивный дизайн для телефона и компьютера.
- Русский и казахский языки.
- Каталог и фильтры категорий.
- Корзина с изменением количества и удалением товаров.
- Формирование заказа и переход в WhatsApp на номер +7 707 776 76 79.
- Цены в тенге.

## Важно перед публикацией
1. В `script.js` проверьте `WHATSAPP_NUMBER`. Сейчас указан `77077767679`.
2. В массиве `PRODUCTS` замените демонстрационные товары, цены, описания и фото на реальные.
3. Текущие фотографии — демонстрационные изображения с внешнего фотохостинга. Лучше заменить их собственными фотографиями товаров.
4. В `index.html` замените ссылку Instagram `href="#"` на свой профиль.
5. Укажите реальные условия доставки, возврата, состав материалов и наличие товара. Не публикуйте неподтверждённые обещания.

## Как заменить фотографии
Создайте папку `images` рядом с `index.html`, положите туда фото, например `soft-taupe.jpg`, а в `script.js` замените поле `image`:
`image: "images/soft-taupe.jpg"`

Названия файлов лучше писать латиницей без пробелов.

## Публикация на GitHub Pages (бесплатно)
1. Откройте https://github.com и создайте бесплатный аккаунт.
2. Подтвердите электронную почту.
3. Нажмите `New repository`.
4. Назовите репозиторий `bage-store` (можно сделать Public).
5. Нажмите `Create repository`.
6. На странице репозитория выберите `Add file` → `Upload files`.
7. Распакуйте архив BAGÉ и перетащите в окно загрузки именно файлы `index.html`, `styles.css`, `script.js`, `README.md` (и папку `images`, если добавили её). Не загружайте ZIP вместо распакованных файлов.
8. Нажмите `Commit changes`.
9. Откройте `Settings` → `Pages`.
10. В разделе `Build and deployment` выберите `Deploy from a branch`.
11. В `Branch` выберите `main`, папку `/ (root)`, нажмите `Save`.
12. Подождите несколько минут. Адрес будет примерно таким:
   `https://ВАШ-ЛОГИН.github.io/bage-store/`

## Как обновлять сайт
Измените нужный файл на компьютере. На GitHub откройте этот файл → значок карандаша (Edit) или `Add file` → `Upload files`, загрузите новую версию и нажмите `Commit changes`. GitHub Pages обновит сайт автоматически через несколько минут.

## Ограничения бесплатной версии
- Заказы открываются в WhatsApp; сайт сам не принимает оплату.
- Нет автоматического учёта остатков, личного кабинета и панели администратора.
- Корзина работает в браузере посетителя и не передаёт заказ на сервер.
- GitHub Pages — публичный хостинг статических файлов. Не размещайте в репозитории персональные данные клиентов, пароли или закрытые документы.
- Адрес GitHub Pages бесплатный. Собственный домен `bage.kz` приобретается отдельно и не нужен для старта.

## Как добавить товар
В `script.js` найдите `const PRODUCTS = [` и добавьте объект по образцу:
```js
{
  id: 7,
  category: "classic", // classic, everyday или evening
  price: 99000,
  image: "images/new-bag.jpg",
  ru: { name: "MODEL NAME", desc: "Описание на русском" },
  kk: { name: "MODEL NAME", desc: "Қазақша сипаттама" }
}
```
Для каждого товара используйте уникальный `id`.
